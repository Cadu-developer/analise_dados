# Projeto — População 2010 x 2022

Arquivos:
- `analise_populacao_2010_2022.ipynb` — notebook da atividade.
- `dados/populacao_por_estado.csv` — população agregada por UF, ordenada pelo crescimento.
- `dados/populacao_por_municipio.csv` — população por município, ordenada pelo crescimento.
- `graficos/10_ufs_maior_crescimento.png` — gráfico das 10 UFs com maior crescimento absoluto.
- `CD2022_Populacao_2010_Compatibilizada_20231222 (1).xlsx - Municípios.pdf` — tabela original fornecida.

Observação: para comparar 2010 com 2022, foi utilizada a população de 2010 compatibilizada para a base territorial de 2022, conforme a observação da tabela do IBGE.
